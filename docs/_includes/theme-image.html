{% comment %} Renders an image that switches by theme (Sligo Jekyll theme uses data-theme on html). Parameters: light (required), dark (optional, falls back to light), alt (required) Example: {% include theme-image.html light="aws-deployment.png" dark="aws-deployment-dark.png" alt="AWS Deployment" %} {% endcomment %} {% assign light_src = site.baseurl | append: "/assets/images/" | append: include.light %} {% assign dark_src = include.dark | default: include.light %} {% assign dark_src = site.baseurl | append: "/assets/images/" | append: dark_src %}
